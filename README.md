# حساب‌یار — نسخه 0.7.0

اپلیکیشن اندروید فارسی و راست‌چین برای ثبت آفلاین تراکنش‌های مالی شخصی. داده‌ها در SQLite محلی ذخیره می‌شوند.

## تغییرات این نسخه
- افزودن دکمه‌های اقدام سریع برای ثبت واریز، ثبت هزینه و بازکردن گزارش‌ها از داشبورد
- اختیاری‌شدن فیلد بانک/حساب مرتبط هنگام ثبت واریز؛ برای پرداخت، حساب مبدأ همچنان اجباری است
- افزودن فیلد «شرکت / محل کار» برای ثبت حقوق و سایر واریزی‌های سازمانی
- نمایش شرکت در فهرست تراکنش‌ها و گزارش مجموع واریزی‌ها بر اساس شرکت
- افزودن فیلتر گزارش‌های همه دوره‌ها، امروز، این هفته، این ماه و ۳۰ روز اخیر
- افزودن چهار تم رنگی قابل انتخاب از تنظیمات (آبی، سبز، بنفش، کهربایی)
- ارتقای دیتابیس با migration برای حفظ تراکنش‌های نسخه قبلی
- افزودن فیلد شرکت به پشتیبان‌گیری و بازیابی JSON

## امکانات پایه
- ثبت پرداخت، واریز و انتقال داخلی
- مبالغ صحیح به تومان و تاریخ شمسی
- جست‌وجو و فیلتر تراکنش‌ها
- محاسبه مانده بر اساس ثبت‌های واردشده
- تهیه و بازیابی پشتیبان JSON
- ساخت APK آزمایشی با GitHub Actions

## ساخت APK
1. فایل‌های ZIP را مستقیماً در ریشه مخزن GitHub جایگزین کنید؛ پوشه `app/` و فایل `settings.gradle.kts` باید در ریشه باشند.
2. از تب Actions گردش کار `Build HesabYar APK` را اجرا کنید.
3. پس از موفقیت، artifact با نام `HesabYar-debug-APK` را دانلود کنید.

## وضعیت تأیید
ساختار ZIP بررسی می‌شود، اما کامپایل Gradle و اجرای روی گوشی در این محیط تضمین نشده است. قبل از واردکردن اطلاعات مالی واقعی، نتیجه Actions و به‌ویژه حفظ داده‌ها پس از به‌روزرسانی را آزمایش کنید.
